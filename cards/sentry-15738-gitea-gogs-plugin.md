## Gap
Self-hosted Git (Gitea/Forgejo) users want the same Sentry commit/PR linking GitHub/GitLab get.

## Why host won't
Sentry staff: not on roadmap - maintenance load of existing SCM integrations blocks new ones. Welcomes community contributions.

## Product angle
Community-quality Gitea/Forgejo plugin or sidecar that maps releases/commits to Sentry, timed to GitHub-exit wave.

## Competition / workarounds
No strong dedicated project found. Could start as open-core plugin with paid support.

## Kill if
Sentry accepts and maintains an official plugin, or Gitea×Sentry customer base is too small to sell.
